# Mes préférences locales

Copier ce fichier dans `.local/PERSONAL.md` pour le personnaliser. `.local/` est ignoré par Git.
Les préférences influencent le travail ; elles n'accordent pas de droits supplémentaires.

- Langue des échanges : français.
- Fuseau pour les dates humaines : Europe/Paris.
- Communication : résultats concrets, explications simples, questions regroupées quand nécessaires.
- Autonomie : avancer sur les actions locales réversibles correspondant à la demande.
- Stack favorite : à renseigner si une préférence réelle existe.
- Budget par projet et services autorisés : à renseigner avant une dépense.
- Actions externes autorisées : préciser les destinations et la portée.
- Données à ne jamais exporter : à renseigner localement, sans les recopier dans les comptes rendus.
